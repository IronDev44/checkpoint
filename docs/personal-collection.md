# Statuts, listes personnelles et contenu

## Suivi des parties
Les actions rapides et la fiche d’un jeu proposent En pause et Abandonné. Le jeu reste dans la collection, sa note est conservée et il n’est pas compté parmi les parties en cours ou terminées. Les vues dédiées de Bibliothèque permettent de le retrouver. Reprendre passe le jeu En cours. Une raison facultative, limitée à 500 caractères, se renseigne dans la fiche, rubrique Dans ta bibliothèque → Suivi de ta partie ; elle reste privée. Les jeux mis de côté ne remontent pas dans les suggestions de prochaine partie.

## Listes personnelles
Bibliothèque → Mes listes : créer et renommer une liste, ajouter des jeux existants, les retirer ou les déplacer, et choisir l’un d’eux comme couverture. Une liste vide peut être créée avant le premier ajout de jeu. Supprimer une liste ne supprime aucun jeu ; l’action peut être annulée tant que ce panneau reste ouvert. Les jeux retirés de la bibliothèque ne sont plus montrés dans la liste ; leur référence est conservée pour une restauration éventuelle. Les listes ne sont pas incluses dans les profils publics.

## Préférences de contenu
Options → Préférences de contenu : choisir les onglets de la barre et les blocs de l’accueil. Accueil et Options restent disponibles. Masquer un onglet actif revient à l’accueil ; un raccourci vers un onglet masqué indique où le réactiver. Le bouton Tout afficher à nouveau réactive les contenus sans changer l’ordre personnalisé. Les blocs utilisent exactement le même réglage que Personnaliser l’accueil.

## Conservation
Les listes et préférences sont dans les réglages privés du compte, les statuts et notes privées dans les documents de jeux. Ces écritures utilisent les files et conflits existants pour le mode hors ligne. Les guides Bibliothèque et Options expliquent les ajouts.
